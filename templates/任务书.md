【自查提示（执行者必须遵守）】
- 遇到 bash 语法错误：用 `bash -n` + **逐行删除法**定位（删掉某行后语法变绿即元凶），**禁止写词法分析器/状态机**调试
- 实现完成后自查：① 所有脚本有可执行权限（chmod +x）② 数值字段的 0 值不丢失（用 `is not None` 判断，勿用 `or ""` 吞 0）③ 管道取退出码用 PIPESTATUS 或重定向

【```flow 前置块（可选，机器可读结构化声明）】
> executor 与 `verify --auto` 读取；缺失不报错但触发回退（fail-closed）。可声明 `test_command` 与 `diff_scope`（allow/deny 为标量序列）：

````
```flow
test_command: python3 -m unittest discover tests
diff_scope:
  allow:
    - scripts/flow-core.py
  deny:
    - scripts/dsh-design
```
````
